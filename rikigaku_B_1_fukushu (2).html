Q1　用語の説明

次の言葉を簡潔に説明しなさい。1と2は単位も書くこと。
1. 速度　2. 加速度　3. 運動の第一法則　4. 運動の第二法則　5. 運動の第三法則

1. 速度(単位: m/s)
位置の時間変化の割合(向きと大きさをもつベクトル)。v=drdt。「速さ」は速度の大きさ v=|v|。
2. 加速度(単位: m/s2)
速度の時間変化の割合(ベクトル)。a=dvdt=d2rdt2
3. 運動の第一法則(慣性の法則)
物体に力がはたらかない(または合力が 0 の)とき、静止している物体は静止を続け、動いている物体は等速直線運動を続ける。
4. 運動の第二法則(運動方程式)
物体の加速度は、はたらく合力に比例し、質量に反比例する。ma=F(すなわち md2rdt2=F)
5. 運動の第三法則(作用反作用の法則)
物体Aが物体Bに力を及ぼすと、BもAに、同じ大きさで逆向き、同一直線上の力を及ぼす。FA→B=−FB→A

書き方のコツ:3つの法則を別々に書き、キーワード(合力0・等速直線運動 / 合力に比例・質量に反比例 / 大きさ等しく逆向き)を入れると安全です。

Q2　ボールの投げ出し(空気抵抗なし → あり)

質量 m のボールを t=0 に速さ v0 で、水平と角度 θ をなす向きに投げる。初期位置は (x,y)=(0,h)、重力加速度の大きさは g。

(1) x, y 方向の運動方程式を立て、時刻 t の速度 v=(vx,vy) と位置 r=(x,y) を求めよ(空気抵抗なし)。

(2) 速度に比例する空気抵抗 −mkv(k は比例定数)がはたらくとして運動方程式を立て、v=(vx,vy) を求めよ。vx–t、vy–t グラフの概形を、空気抵抗なしの場合も重ねて描け。

(1) 空気抵抗なし

【基本の解き方】運動方程式 → 積分を2回

運動方程式(座標軸の向きを正とする。重力は −y 向き)

md2xdt2=0(x 方向)
md2ydt2=−mg(y 方向)

1回積分して速度(初期条件: vx(0)=v0cosθ、vy(0)=v0sinθ)

vx=v0cosθ,vy=v0sinθ−gt

もう1回積分して位置(初期条件: x(0)=0、y(0)=h)

x=v0cosθ·t,y=h+v0sinθ·t−12gt2

【もっと楽な方法】等加速度運動の公式に代入するだけ

加速度が一定なら、次の公式が使えます(積分した結果そのものです)。

v=v初+at,x=x初+v初t+12at2

x 方向は a=0、y 方向は a=−g を入れれば一瞬で同じ答えになります。「初速・初期位置・加速度」の3つを拾うのがコツです。

答え

v=(v0cosθ, v0sinθ−gt)
r=(v0cosθ·t, h+v0sinθ·t−12gt2)

(2) 空気抵抗 −mkv あり

【基本の解き方】運動方程式 → x と y を別々に解く

運動方程式(抵抗のベクトルを成分に分ける)

mdvxdt=−mkvx
mdvydt=−mg−mkvy

x 方向: m を消して変数分離します。

dvxvx=−kdt → lnvx=−kt+C → vx=v0cosθ·e−kt

y 方向: u=vy+gk とおくと dudt=−ku となり、x 方向と同じ形になります。

u=u0e−kt,u0=v0sinθ+gk
vy=(v0sinθ+gk)e−kt−gk

【もっと楽な方法】「最終速度」を先に決めて公式に入れる

抵抗ありの1階の式は、どれも次の形になります。

v(t)=v∞+(v初−v∞)e−kt

v∞ は加速度が 0 になる速度(終端速度)で、運動方程式の右辺 =0 から出します。

  • x 方向: −mkvx=0 より v∞=0、初速 v0cosθ なので vx=v0cosθ·e−kt
  • y 方向: −mg−mkvy=0 より v∞=−gk、初速 v0sinθ なので上の答えと一致

微分方程式を解かずに数秒で書け、検算(t=0 で初速、t→∞ で終端速度)にもなります。

答え

vx=v0cosθ·e−kt
vy=(v0sinθ+gk)e−kt−gk

グラフの概形(点線: 空気抵抗なし、実線: 空気抵抗あり)

描くときのポイント:どちらも t=0 は同じ出発点で、終わり方(vx→0、vy→−gk)を必ず描きます。vy は最初、抵抗ありのほうが急に減り(重力も抵抗も下向き)、のちに直線と交わって、以降は抵抗ありのほうが上になります。グラフは v0sinθ>0 の場合です。

Q3　斜面上の物体と力積

摩擦のある角度 θ の斜面上に質量 m の物体を置き、図のように時間変化する外力 F を加える。F が F0 になった時刻 t0 に動き出した。外力は斜面に沿って下向きを正とする。静止摩擦係数と動摩擦係数の比は 2:1。

(1) 時刻 0〜t1 に F が物体に与える力積 IF
(2) 静止摩擦係数
(3) 動いているときの摩擦力の大きさ
(4) 時刻 0〜t1 に摩擦力が及ぼす力積 IR(IR–t グラフも)
(5) 時刻 t1 での速さ v1

【前提】問題文の「水平方向」は、図(F の矢印が斜面に沿っている)と「斜面に沿って下向きを正」という記述から、斜面に沿った方向として解きます。このとき垂直抗力は N=mgcosθ です。また、t0 以降は t1 まで下向きに動き続けている(止まらない)ものとします。

(1) F の力積 IF

【基本の解き方】力積 =∫Fdt= グラフの面積

グラフ全体は、底辺 t1、高さ 3F0 の三角形です。

IF=12×t1×3F0=32F0t1

答え

IF=3F0t12

(2) 静止摩擦係数 μs

【基本の解き方】「動き出す直前」は最大静止摩擦力でつりあう

動き出す直前(F=F0)、摩擦力は上向き(−x 向き)で最大値 μsN です。

N=mgcosθ(斜面に垂直)
F0+mgsinθ−μsN=0(斜面に平行)
μs=F0+mgsinθmgcosθ=tanθ+F0mgcosθ

検算: F0=0(力なしで滑り出す限界)なら μs=tanθ。斜面の摩擦角の公式と一致します。

答え

μs=F0+mgsinθmgcosθ

(3) 動いているときの摩擦力の大きさ

【基本の解き方】μk=μs2 を使う

f′=μkN=μs2·mgcosθ=F0+mgsinθ2

【もっと楽な方法】μ を経由しない

(2)で「最大静止摩擦力 =F0+mgsinθ」がすでに出ています。動摩擦力は同じ N を使うので、係数の比 12 がそのまま力の比になります。つまり最大静止摩擦力の半分です。

答え

f′=F0+mgsinθ2(一定、上向き)

(4) 摩擦力の力積 IR

下向きを正としているので、摩擦力(上向き)は負として扱います。

【基本の解き方】区間を分けて足す

  • 0~t0(静止中): 静止摩擦力で、つりあいから f(t)=F(t)+mgsinθ=F0t0t+mgsinθ(t とともに増加)
  • t0~t1(運動中): f′=F0+mgsinθ2(一定)
IR=−∫0t0(F0t0t+mgsinθ)dt−F0+mgsinθ2(t1−t0)
=−(F0t02+mgsinθ·t0)−(F0+mgsinθ)(t1−t0)2
=−(F0+mgsinθ)t1+mgsinθ·t02

【もっと楽な方法】摩擦力–時間グラフの面積(台形 + 長方形)

台形=mgsinθ+(F0+mgsinθ)2×t0=F0t02+mgsinθ·t0
長方形=F0+mgsinθ2×(t1−t0)

積分せずに面積を足すだけで、上と同じ結果になります。

答え

IR=−(F0+mgsinθ)t1+mgsinθ·t02(上向き)

(5) 時刻 t1 での速さ v1

【基本の解き方】力積と運動量の関係(0~t1 全体)

t0 までは静止していたので、初めの運動量は 0。斜面方向の力は、F・重力成分 mgsinθ・摩擦力の3つです。

mv1=IF+mgsinθ·t1+IR
mv1=32F0t1+mgsinθ·t1−(F0+mgsinθ)t1+mgsinθ·t02
mv1=F0t1+mgsinθ2(t1−t0)

【もっと楽な方法】動き出した t0 以降だけ考え、合力を1本にまとめる

t0 までは静止なので、静止摩擦の区間(台形)は計算しなくて構いません。t0 以降の合力(下向き正)は

F+mgsinθ−F0+mgsinθ2=F+mgsinθ−F02

力積は「F–t グラフの t0~t1 の面積」+「一定の項 ×(t1−t0)」です。

mv1=(32F0t1−12F0t0)+mgsinθ−F02(t1−t0)=F0t1+mgsinθ2(t1−t0)

基本の解き方と同じ結果になります。2通りで一致すれば検算完了です。

答え

v1=F0t1m+gsinθ2(t1−t0)

Q4　滑らかな斜面上のバネ

角度 θ の固定された滑らかな斜面に、バネ定数 k のバネの一端を固定し、他端に質量 m の質点をつける。t=0 にバネが自然長の位置で静かに放す。自然長の位置を原点とし、斜面下向きに x をとる。

(1) バネの伸びが x の位置での運動方程式を書き、エネルギー保存則を導け。

(2) (1)のエネルギー保存則から、速さが最大となる位置が x1=mgksinθ(振動中心)であることを示せ。

(1) 運動方程式とエネルギー保存則

【基本の解き方】運動方程式に速度 v=dxdt をかけて積分

運動方程式(斜面下向き正): 重力の斜面成分 mgsinθ(下向き)とバネの力 −kx(上向き)がはたらきます。垂直抗力は斜面に垂直なので x 方向には効かず、滑らかなので摩擦もありません。

md2xdt2=mgsinθ−kx

両辺に v=dxdt をかけると、それぞれ時間微分の形にまとまります。

mvdvdt=mgsinθ·dxdt−kx·dxdt
ddt[12mv2]=ddt[mgsinθ·x−12kx2]

右辺を左辺に移すと、[ ] 内が時間によらず一定と分かります。

12mv2+12kx2−mgsinθ·x=一定

初期条件 t=0 で x=0、v=0 なので、一定値は 0 です。

答え

12mv2+12kx2−mgsinθ·x=0

意味の読み取り:第1項は運動エネルギー、第2項はバネの弾性エネルギー、第3項は重力の位置エネルギーです(x だけ下ると高さが xsinθ 下がるので −mgxsinθ)。この3つの合計が保存されます。

【もっと楽な方法】vdvdt ではなく vdvdx に置き換える

連鎖律より dvdt=dvdxdxdt=vdvdx なので、

mvdvdx=mgsinθ−kx

これを x で 0 から x まで積分すると(左辺は v を 0 から v まで積分)

12mv2=mgsinθ·x−12kx2

初期条件を積分の下端に入れるので、一定値を別に求める手間が省けます。

(2) 速さ最大の位置

【基本の解き方】平方完成して最大値を読む

(1)の式を v2 について解きます。

v2=1m{2mgsinθ·x−kx2}

{ } の中を平方完成します。

v2=1m{−k(x−mgsinθk)2+(mgsinθ)2k}

−k(⋯)2 は 0 以下なので、v2 は括弧の中が 0 のとき最大です。すなわち

x1=mgksinθ(このとき vmax=gsinθmk)

【もっと楽な方法】「力のつりあいの位置」で速さが最大になる

速さが最大 ⇔ 加速度が 0(v が極大なので dvdt=0) ⇔ 力のつりあい。(1)の運動方程式より

mgsinθ−kx1=0 → x1=mgsinθk

エネルギーの式から出す場合も、v2 を x で微分して 0 とおけば 2mgsinθ−2kx=0 となり、同じ式が出ます。

答え

x1=mgksinθ(速さは x=x1 で最大、これが振動中心)
